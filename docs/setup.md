# 環境の準備と開発ストアの設定

このテーマを開発ストアで動かすまでの手順です。上から順に進めてください。

## 1. Shopify パートナーアカウントと開発ストア

1. https://www.shopify.com/jp/partners から「パートナーになる」を選び、無料のパートナーアカウントを作る
2. パートナーダッシュボードの「ストア」→「ストアを追加」→「開発ストアを作成」
   - 用途は「テストとクライアント向けのストアを構築する」を選ぶ
   - ストア名：例 `yuiha-do-sample`（URL は `yuiha-do-sample.myshopify.com` になる）
   - 開発ストアは無料。実際の決済はできず、ストアの表示にはパスワードがかかる
3. 作成したストアの管理画面に入れることを確認する

## 2. Shopify CLI

Node.js（18 以上）が入っていれば、次の 1 行で入る。

```bash
npm install -g @shopify/cli
shopify version
```

## 3. テーマをローカルで動かす

このリポジトリのフォルダで実行する。

```bash
# 初回はブラウザでログインを求められる
shopify theme dev --store yuiha-do-sample.myshopify.com
```

- 表示された `http://127.0.0.1:9292` をブラウザで開くと、ローカルのコードでストアをプレビューできる
- ファイルを保存すると自動で反映される
- テーマエディタ（管理画面のカスタマイズ）で確認したいときは、表示される「Customize」の URL を開く

完成したら、開発ストアにテーマとしてアップロードする。

```bash
shopify theme push --unpublished --store yuiha-do-sample.myshopify.com
# 管理画面の「オンラインストア > テーマ」で、アップロードしたテーマを「公開」する
```

コードのチェック：

```bash
shopify theme check
```

## 4. ストアの基本設定（管理画面）

| 場所 | 設定 |
|---|---|
| 設定 > ストアの詳細 | ストア名「結葉堂」、通貨は日本円 |
| 設定 > 言語 | 日本語をデフォルトに。英語を追加して公開 |
| 設定 > マーケット | 「海外」または「United States」のマーケットを作り、通貨を米ドルにする |
| 設定 > 配送と配達 | 国内の送料 600円、条件「5,000円以上で無料」（テーマの送料無料バーと同じ金額にする） |
| オンラインストア > 各種設定 | パスワード保護は開発ストアでは外せない。パスワードは応募先にだけ伝える |

英語・米ドルが有効にならない場合でも、テーマ設定「言語・通貨の切り替え」で表示位置を切り替えられることは、テーマエディタで確認できます（切り替えの部品は、言語または国が 2 つ以上あるときだけ表示されます）。

## 5. 商品の登録

1. 管理画面「商品」→「インポート」で `store-setup/products.csv` を読み込む（7 商品＋ギフト包装料）
2. 商品画像を 1 点ずつ追加する（下の「画像」を参照）
3. 「ギフト包装料」は商品タイプ「包装料」になっていることを確認する

### コレクション

「商品」→「コレクション」→「コレクションを作成」

| コレクション名 | ハンドル | 条件 |
|---|---|---|
| 商品一覧 | `shop` | 自動：商品タイプ が「包装料」と等しくない |
| 秋のギフト | `autumn` | 自動：タグ が「秋」と等しい |

トップページの「人気のギフト」とボタンは、ハンドル `shop` のコレクションを表示します。包装料の商品が一覧に出ないようにするためです。

### メニュー

「オンラインストア」→「メニュー」→ main-menu を次のように変更する。

- ホーム → `/`
- 商品一覧 → コレクション「商品一覧」
- 季節のギフト特集 → ページ「季節のギフト特集」

### 画像

ライセンス上問題のないフリー素材を使う（商用利用可・クレジット不要のもの）。

- Unsplash（https://unsplash.com/ja）または Pexels（https://www.pexels.com/ja-jp/）
- 検索語の例：`green tea`、`matcha`、`hojicha`、`tea leaves`、`coffee beans`、`pour over coffee`、`gift box japanese`
- 使った画像の撮影者と URL を README の「画像の出典」に書く
- メインビジュアル用に横長（1920px 以上）を 1〜2 枚、商品用に正方形に切り抜ける写真を 7 枚
- 実在するブランドのロゴやパッケージが写っている写真は避ける

## 6. 特集ページ

1. 「オンラインストア」→「ページ」→「ページを追加」
2. タイトル「季節のギフト特集」、ハンドル `gift-feature`
3. 右側の「テーマテンプレート」で `gift-feature` を選んで保存
4. テーマエディタでこのページを開き、「メインビジュアル」の画像と「商品ピックアップ」の商品を選ぶ

## 7. テーマ設定

テーマエディタ →「テーマ設定」（歯車のアイコン）

- 「ギフト包装」→ 包装料の商品に「ギフト包装料」を選ぶ（インポート直後は自動で選ばれている）
- 「送料無料バー」→ 5,000円、ほかの通貨 `USD:35`
- 「言語・通貨の切り替え」→ ヘッダー（右上）
- 「見出し（かんたん設定）」→ Shippori Mincho

詳しくは [オーナー向け手順メモ](owner-guide.md) を参照。
