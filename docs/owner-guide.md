# ストアの見た目を自分で変える方法（オーナー向け）

このメモの設定は、すべて**管理画面のテーマエディタ**で変えられます。コードを触る必要はありません。
変更はプレビューにすぐ表示され、右上の「保存」を押すまでお客様の画面には反映されません。

## テーマエディタの開き方

1. Shopify の管理画面にログインする
2. 左のメニューで「オンラインストア」→「テーマ」を開く
3. 公開中のテーマの「カスタマイズ」を押す


> 迷ったときは：保存する前なら、ブラウザを閉じれば変更は消えます。保存したあとでも、同じ項目を元の値に戻せば元どおりになります。

---

## 1. 見出しのフォント・大きさ・色を変える

左下の歯車アイコン「テーマ設定」→「**見出し（かんたん設定）**」


| 項目 | できること |
|---|---|
| 見出しの日本語フォント | 明朝体（Shippori Mincho など）やゴシック体を選ぶ。「テーマのフォントを使う」にすると英字のフォントに戻る |
| 見出しの太さ | 標準・やや太い・太い |
| スマートフォンでの見出しの大きさ | スマートフォンで見出しが大きすぎるときに、70〜100% で小さくする |
| 文字の間隔 | 見出しの文字と文字のすき間 |
| 見出しの色 | 白い背景（配色「スキーム1」）の見出しの色。空欄にすると本文と同じ色に戻る |

**PC での見出しの大きさ**は、同じ「テーマ設定」の「タイポグラフィー」→「見出し」の「拡大」（100〜150%）で変えます。

### 特集ページの見出しを 1 つだけ大きくしたいとき

テーマエディタで特集ページを開き、左の一覧でブロック（例：「よくある質問（FAQ）」）を選ぶと、「見出しの大きさ」を小・中・大から選べます。


---

## 2. ギフト包装・のし・メッセージカード

### 包装料を変える

包装料は「ギフト包装料」という商品の価格です。管理画面の「商品」→「ギフト包装料」で価格を変えると、商品ページの「ギフト包装する（+330円）」の金額も自動で変わります。

### のし・カードの選択肢を変える

テーマエディタの上部で「商品ページ」を開く →「商品情報」の中の「**ギフトオプション**」ブロック


- 「のしの選択肢」「メッセージカードの選択肢」に **1 行に 1 つずつ** 書く。1 行目が最初に選ばれた状態になる
- 不要な欄は「〜を表示する」のチェックを外すと消える
- 「補足の文章」は選択欄の下に小さく表示される

### 包装料の商品について（削除しないでください）

- 「ギフト包装料」の商品を削除・下書きにすると、商品ページのギフト包装が選べなくなります
- 包装料は、商品と一緒にカートに入り、数量も商品と同じになります。商品をカートから削除すると、包装料も一緒に削除されます

## 3. 送料無料までの残り金額バー

「テーマ設定」→「**送料無料バー**」


- 「送料無料になる金額」：円で入力する。**「設定 > 配送と配達」の送料無料の条件と同じ金額**にしてください（バーは表示だけで、実際の送料は配送設定で決まります）
- 「ほかの通貨での金額」：海外向けに米ドルなどで販売するときに `USD:35` のように書く
- バーを出したくないときは、チェックを外す

---

## 4. 言語・通貨の切り替えの場所

「テーマ設定」→「**言語・通貨の切り替え**」→「切り替えを表示する場所」


- ヘッダー（右上）／フッター／両方 から選ぶ
- スマートフォンでは、「ヘッダー」を選ぶとメニューの中に表示されます
- 「国・通貨」と「言語」のどちらを出すかは、「ヘッダー」「フッター」セクションの「国/地域セレクター」「言語セレクター」のチェックで選びます
- 切り替えは、ストアで言語または国が 2 つ以上有効になっているときだけ表示されます

---

## 5. 特集ページ（LP）を作る・並べ替える

1. 管理画面「オンラインストア」→「ページ」→「ページを追加」
2. 右側の「テーマテンプレート」で `gift-feature` を選んで保存
3. テーマエディタの上部でそのページを開く


- 左の一覧の「ブロックを追加」から、**メインビジュアル・商品ピックアップ・テキスト・よくある質問（FAQ）・行動ボタン（CTA）** を追加できる
- ブロックの左の「⋮⋮」をドラッグすると順番を入れ替えられる
- 目のアイコンで一時的に非表示にできる
- 別の季節の特集を作るときは、新しいページを作って同じテンプレートを選ぶか、テンプレートを複製する

---

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 商品ページにギフトオプションが出ない | 「テーマ設定 > ギフト包装」で包装料の商品が選ばれているか。「ギフト包装料」の商品が「アクティブ」でオンラインストアに公開されているか |
| 送料無料バーが出ない | 「送料無料バー」のチェック、金額が 0 になっていないか。米ドルで見ている場合は「ほかの通貨での金額」に USD があるか |
| 言語の切り替えが出ない | 「設定 > 言語」で英語が公開されているか |
| 変更が反映されない | テーマエディタ右上の「保存」を押したか |
